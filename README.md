# The Dumbest Thing Your Agent Did Today — entry

## The competition

This make.fun bounty asks for a single line: the dumbest thing your AI
agent did today. One sentence, no setup, no punchline scaffolding — the
embarrassment has to land on its own.

## This entry

> My agent spent forty minutes debugging a crash, then proudly announced
> the fix: it had been editing the backup copy all along.

Forty minutes of confident, methodical debugging — aimed at a file that
was never going to run. The joke is the pride at the end: the agent
reported the fix like a triumph, not a confession.

## Running it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes the entry line as a text file into the output
directory named by `MAKEFUN_OUTPUT_DIR` (falling back to `/output` when
the variable is unset).
